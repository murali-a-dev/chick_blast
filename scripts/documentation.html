📌 1. Executive Summary & Overview

Chick Blast is an end-to-end commercial restaurant technology platform designed for fried chicken outlets, cloud kitchens, and takeaway diners. The ecosystem delivers a frictionless omni-channel customer ordering experience coupled with an automated back-of-house Kitchen Display System (KDS) and store management analytics.

🍗 Customer Storefront

High-converting, responsive food catalog with real-time search, interactive hero carousel, instant cart calculation, and multi-mode fulfillment (Dine-In, Takeaway, Home Delivery).

👨‍🍳 Kitchen Display (KDS)

Paperless kitchen operation pipeline with live order statuses, preparation countdowns, customer order tickets, and one-tap stage progression.

📊 POS & Analytics

Store management dashboard with revenue analytics, Recharts visualizations, dynamic product CRUD, bundle/combo deals builder, and date-filtered order reporting.

🏗️ 3. System Architecture & Data Pipeline

The system follows a decoupled Single Page Application (SPA) architecture with an Express.js API gateway and Google Cloud Firestore.

1. Storefront Client
React 19 SPA routes orders, cart state, and customer persistence via context providers.
2. API Gateway
Express 5 router executes validation, caching headers, and Multer multipart processing.
3. Firebase Cloud
Firestore NoSQL stores documents with atomic updates for live inventory and orders.
4. KDS & POS Admin
Live synchronization updates kitchen monitors and administrative dashboards.

⚡ 4. Detailed Feature Specifications

🛒 Customer-Facing Storefront Features

  • Interactive Digital Catalog: Real-time category selector tabs (Crispy Fried Chicken, Burgers, Combos, Beverages, Fries & Sides, Desserts) with immediate search matching.
  • Signature Hero Showcase: Rotating dynamic carousel spotlighting signature recipes with spice ratings, prep times, and quick-add shortcuts.
  • Comprehensive Product Modal: Shows detailed nutritional badges, portion sizes, spice level indicators, and certified FSSAI food hygiene tags.
  • Smart Multi-Channel Cart:
    • Switch between Takeaway, Dine-In, or Home Delivery.
    • Subtotal, delivery surcharges, GST/tax calculation, and net billing automatically computed.

  • Custom Food-Themed 404 Experience: Playful fallback page ("Oops! This Chicken Flew Away 🍗") preventing lost conversions and guiding customers back to the menu.

👨‍🍳 Kitchen Display System (KDS) & Admin POS Features

  • Live Kitchen Stream (KDS): Real-time card feed showing active tickets with elapsed timers, order itemizations, special requests, and single-click stage advances.
  • Executive Analytics Dashboard: Key metrics at a glance: Total Daily/Weekly Gross Revenue, Completed Ticket Count, Average Ticket Size, and Recharts graphical performance curves.

  • Asset Upload Pipeline: Direct image uploading handled via Multer middleware into server storage with generated asset URLs.

📡 5. REST API Specifications

Method Endpoint Parameters / Body Description
GET /api/health None Server status and health check probe.
GET /api/items ?category=... Fetch all active menu items and bundled combo meals.
POST /api/items JSON Item Payload Add a new food item or combo package into catalog.
PUT /api/items/:id Updated Fields Update pricing, stock availability, or description of an item.
DELETE /api/items/:id URL :id Remove or deactivate an item from active menu listings.
GET /api/orders ?fromDate=&toDate=&phone= Retrieve orders list with flexible date and phone filtering.
GET /api/orders/:id URL :id Fetch detailed progress status and receipt for a single order.
POST /api/orders Order Ticket Payload Submit and store new customer order with line items and customer info.
PATCH /api/orders/:id/status { "status": "Preparing" } Advance order stage (Pending → Preparing → Packed → Delivered).
GET /api/dashboard/stats ?range=today|week|month Compute aggregate revenue, order counts, and top selling items.
GET /api/customers ?phone=... Query repeat customer information and historic order frequencies.
POST /api/upload Multipart Form File Upload product imagery to server assets storage via Multer.

🚀 8. Getting Started & Deployment Guide

🌐 Live Production URL

The live customer application is accessible at: https://chick-blast.vercel.app

Local Environment Setup

# 1. Clone repository
git clone https://github.com/muraliofficial/chick_blast.git
cd chick_blast

# 2. Install dependencies
npm install

# 3. Configure environment variables in .env
PORT=3001
VITE_API_URL=http://localhost:3001
FIREBASE_PROJECT_ID=your_firebase_project_id
FIREBASE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"
FIREBASE_CLIENT_EMAIL=your_client_email@your_project.iam.gserviceaccount.com

# 4. Start concurrent development server
npm run dev
